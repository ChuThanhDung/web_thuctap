# Quy tac thiet ke va cau truc du an

## 1. Giao dien

- Tat ca ma nguon giao dien phai nam trong folder `frontend`.
- Khi thiet ke, chinh sua hoac tao moi bat ky trang giao dien nao, bat buoc phai doc file `frontend/DESIGN.md` truoc.
- Cac thanh phan giao dien moi can tuan thu phong cach, mau sac, spacing, typography va pattern da duoc dinh nghia trong `frontend/DESIGN.md`.

## 2. Backend

- Backend su dung Python voi FastAPI.
- Tat ca ma nguon backend phai nam trong folder `src`.
- Cac API, service, model, schema va logic xu ly phia server can duoc to chuc ben trong `src` theo cau truc hien co cua du an.

## 3. Database

- Database chinh cua du an la PostgreSQL.
- Khi thiet ke tinh nang moi co lien quan den du lieu, can uu tien schema, truy van va migration tuong thich voi PostgreSQL.

## 4. Quy trinh truoc khi thiet ke giao dien

Truoc khi bat dau thiet ke bat ky trang giao dien nao:

1. Mo va doc file `frontend/DESIGN.md`.
2. Xac dinh cac quy tac thiet ke lien quan den trang can lam.
3. Ap dung dung design system da co thay vi tu tao phong cach moi.
4. Chi bo sung pattern moi khi that su can thiet va khong mau thuan voi `frontend/DESIGN.md`.
